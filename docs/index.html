What Portably is

Portably is a way of working for AI agents that turn a design into a website or an application screen. You give the agent a design: a Figma file, screenshots, an existing page or a written brief. The agent builds it into plain HTML, CSS and JavaScript on one complete design system, in a structure every Portably project shares, and checks the result with one command.

The design decides what is built: how it looks, what it contains, how it behaves. Portably decides how it is organised and where every value comes from. Two designs built with Portably look nothing alike and feel equally familiar in source.

How it works

  1. 1 · InputA designFigma, screenshots, a site or a brief.
  2. 2 · BuildAn AI agentFollows Portably's guide, tokens first.
  3. 3 · Verifycheck and fixSafe fixes are automatic; decisions are explicit.
  4. 4 · OutputA documented projectAnyone can continue it, with or without Portably.

The agent reads Portably's AGENTS.md, creates the project with init, records the design's colours, type, spacing and shapes in tokens/tokens.json, builds the pages, and runs check until it passes. Along the way it writes down where the design came from and every decision the code can't show.

Why it exists

An agent can turn a design into working code quickly. What it leaves behind is usually harder to live with: values typed by hand in hundreds of places, a structure invented for this one project, and decisions that only exist in a chat that's now closed. The next agent or developer has to reverse-engineer all of it.

Portably gives the agent a system to build into, and a check that keeps it honest, so the result can be continued by anyone from the repository alone.

What it isn't

  • Not a framework or a runtime. The finished project is ordinary HTML, CSS and JavaScript. It runs without Portably and has no build step.
  • Not a visual style or a component library. Portably ships a reset, a button and a skip link. Everything else comes from the design.
  • Not tied to one AI tool. Any agent that can read files and run a command can follow it, and so can a person.

Who it's for

Portably is for anyone who asks an AI agent to build a frontend and needs the result to last: designers who build their own sites, teams without a mature frontend system, and developers who will take a project over later. It suits websites, landing pages, prototypes and application screens that should stay easy to change.
