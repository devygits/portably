# Portably documentation

The published Portably documentation site. It is itself a Portably project, so it follows the same rules as any project built with Portably.

## Pages

- `index.html`: introduction, what Portably is and isn't.
- `pages/quickstart.html`, `pages/installation.html`: getting started.
- `pages/workflow.html`, `pages/design-system.html`, `pages/structure.html`, `pages/check.html`: how it works.
- `pages/output.html`, `pages/other-stacks.html`: the output, and moving it to another stack.
- `pages/sample.html`: this site's generated `DESIGN-SYSTEM.html`, shown below the site header (`?embed`) and following the site's theme; "Back to docs" returns to the page the reader came from.
- `pages/commands.html`, `pages/findings.html`, `pages/configuration.html`, `pages/theming.html`, `pages/accessibility.html`: reference.

Every page has a dark (default) and a light theme, and a menu for the sidebar on small screens (on the design-system sample, a back arrow instead).

## Known gaps

- No search; the sidebar lists every page.
- Long lines in code blocks scroll inside their box on narrow screens; the page itself doesn't.
- `DESIGN-SYSTEM.html` shows the default dark roles; the light roles are overrides in `css/base.css`.

## More

- [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md): the design system, generated by Portably; [DESIGN-SYSTEM.html](DESIGN-SYSTEM.html) shows it in a browser.
- [AGENTS.md](AGENTS.md): how to work on this site and check it.

Run from the repository root: `python portably.py check docs --strict`.
