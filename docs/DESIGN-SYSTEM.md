# Design system

Generated by Portably from `tokens/tokens.json`, `portably.config.json` and the project's HTML and CSS. Don't edit this file by hand: change those, then run `python portably.py check`. `DESIGN-SYSTEM.html` shows the same system drawn with the project's own tokens.

## Where this design came from

Source: Portably's documentation site, designed directly in code in September 2026 around the Portably logo (SVG files supplied by the owner) and a common documentation layout: a sidebar, the article and a list of its sections.

### Assumptions

Decisions made where the source was silent or unclear, including values Portably's defaults filled in.

- The logo defines no palette; the violet action colour and the neutrals are derived from the logo, and the code colours are chosen to sit with them; all pass contrast in both themes.
- Dark is the default theme; a visitor's choice of the light theme is remembered on their device.
- Text uses Inter, stored with the site, and code uses the visitor's system monospace font; the logo is the only other brand lettering.

### Deviations from the source

Deliberate differences: substituted fonts, images or icons, simplifications, changes that were asked for. Colours changed for readability are listed further down.

- The layout leaves out a search field: with fourteen pages, the sidebar is enough.

## What this project decided
