Getting started

Quickstart

Build a design with an AI agent. You need Python, the design and one sentence.

With an AI agent

  1. Download Portably

    Put it next to where the project will live, not inside it. See Installation for the requirements.

    git clone https://github.com/devygits/portably

  2. Give the agent the design and one sentence

    Attach or link the design, then ask:

    Build this design with Portably. Read portably/AGENTS.md first and create the project in site/.

  3. Let it build and check

    The agent creates the project, records the design system in tokens/tokens.json, builds the pages and runs the check until it passes. It uses the findings as data:

    python portably/portably.py check site --json
python portably/portably.py fix site
python portably/portably.py check site --strict

  4. Review the handoff

    Open site/index.html in a browser. Read site/DESIGN-SYSTEM.md for where the design came from, what the agent assumed and what it changed. Open site/DESIGN-SYSTEM.html to see the design system drawn with its own tokens.

By hand

Portably works without an agent too. Create a project, then follow the project's own AGENTS.md:

python portably/portably.py init site
python portably/portably.py check site

Record where the design comes from in site/portably.config.json, put its colours, fonts and sizes in site/tokens/tokens.json, then replace the placeholder page and style it in site/css/. Run check whenever you want to know what's left.
