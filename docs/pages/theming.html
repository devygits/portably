Theming

The colour roles are the theming API. A theme points the same roles at other palette colours.

Dark and light

Add the mode's colours to the palette in tokens.json, then point the roles at them under an attribute or a media query. Components don't change.

.pbly[data-theme="dark"] {
  --pbly-color-background: var(--pbly-color-palette-night);
  --pbly-color-text-primary: var(--pbly-color-palette-snow);
  --pbly-color-text-muted: var(--pbly-color-palette-mist);
  --pbly-color-surface-raised: var(--pbly-color-palette-night-raised);
  --pbly-color-border-default: var(--pbly-color-palette-night-line);
}

For the visitor's system setting, put the same overrides inside @media (prefers-color-scheme: dark). Overrides point at palette tokens, never raw colours; check flags raw colours. check finds both kinds of theme and measures the text of every page in each one.

This site

This documentation is dark by default. Its tokens hold both palettes, and the theme toggle points the roles at the light one. The code blocks keep their own roles, so they stay dark in both themes.

check finds the light theme in the CSS and measures every page in it as well as in the default dark one.

Sections with their own colours

The same pattern works for any number of contexts, such as a page that alternates dark and light sections:

.pbly .ground-dark {
  --pbly-color-background: var(--pbly-color-palette-pine);
  --pbly-color-text-primary: var(--pbly-color-palette-snow);
  background: var(--pbly-color-background);
  color: var(--pbly-color-text-primary);
}

When a context needs a role Portably doesn't have, such as a chip background, add it under color.* in tokens.json and override it the same way. The browser check measures text in every context, so each one must be readable on its own.

Brand variations

A project changes the values behind the roles in tokens.json; it never renames public classes or edits foundation/. The button takes its shape from the button.* tokens and its colours from the action roles, so a rounder or roomier button is one line in tokens.json.
