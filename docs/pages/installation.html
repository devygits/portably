Getting started

Installation

Portably is a folder with one Python command. There is nothing to install into your project.

Requirements

  • Python 3.9 or newer. That's all init, check, fix and promote need.
  • Playwright and Chromium for the final check. check opens every page in a browser to measure text contrast, sideways scrolling, text cut off at the edge, broken images and script errors. Without it the check still runs, but a strict handoff can't pass.

Download Portably

Clone the repository, or download it as a ZIP from GitHub, into its own folder next to your projects:

git clone https://github.com/devygits/portably
workspace/
├── portably/     Portably itself
└── site/         your project, created with init

Keep them apart

Never create the project inside the Portably folder, and never copy Portably's tools/, standard/, tests/ or docs/ into a project. A project carries its own copy of the few files it needs.

Add the browser checks

pip install playwright
playwright install chromium

If a machine really can't run a browser, check --no-browser skips those checks and records a note, so --strict keeps failing. Say so in the project's README.

Check that it works

python portably/portably.py --version
Portably 1.0

Every project records the Portably version it was built with, in portably.config.json. check mentions it when a project was built with a different major version.
