Commands

Portably is one command with four subcommands. Run any of them with --help for the details.

init

python portably.py init <folder> [--namespace acme]

Creates a project from the Portably starter in a new or empty folder, outside the Portably folder. --namespace sets the prefix for Portably's classes and custom properties (default pbly): a lowercase letter first, then lowercase letters, numbers and single hyphens.

check

python portably.py check [<folder>] [--json] [--strict] [--all] [--no-browser]

Checks the project (the current folder by default), regenerates tokens/tokens.css, DESIGN-SYSTEM.md and DESIGN-SYSTEM.html, and explains what needs attention.

OptionWhat it does
--jsonPrints the findings as data, for agents and tools.
--strictAlso fails on notes. Use it before a handoff.
--allLists every finding instead of the first 12 in each group.
--no-browserSkips the browser checks. It records a note, so --strict fails.

fix

python portably.py fix [<folder>] [--json] [--strict] [--all] [--no-browser]

Makes the safe fixes, lists what it changed, then checks again with the same options as check.

promote

python portably.py promote <folder> <kind> <value> [--as <token.name>]

Adds a repeated value to the design system and uses the new token everywhere the value appears.

KindExampleName

Exit codes

CodeMeaning
0Nothing to fix or decide (and, with --strict, no notes).
1There are findings that block the handoff.
2The project couldn't be checked at all, for example because tokens.json is missing. With --json, the reason is in "error".

python portably.py --version prints the Portably version.
