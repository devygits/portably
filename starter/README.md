# Project name

Plain HTML, CSS and JavaScript built with [Portably](https://github.com/devygits/portably). It needs no build step; open `index.html` in a browser.

## Pages

- `index.html`: replace with a one-line description of each page and the states it shows.

## Known gaps

- Pages, states or interactions not built yet, links that point at a stand-in section, and anything loaded from another website.

## More

- [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md): the design system, where the design came from, assumptions, deviations and deliberate exceptions. Generated by Portably from `tokens/tokens.json` and `portably.config.json`; [DESIGN-SYSTEM.html](DESIGN-SYSTEM.html) shows it in a browser.
- [AGENTS.md](AGENTS.md): how to work on the project and check it, for people and AI agents.

Names that start with `pbly` (`pbly-btn`, `--pbly-color-text-primary`) come from Portably. The project's own classes have plain names.
